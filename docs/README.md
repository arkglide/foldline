- 启动维护已修复 Windows 的 `spawn npm ENOENT` 和第二次启动时 CRLF 缓存误报；当前启动回归8项通过，真实固定引擎的CRLF缓存连续两次准备及浏览器初始化通过，仍非原生Windows实测。详见[缓存启动修复](startup-cache-fix.md)，未调整关卡或引擎版本。
- 旧版三项浏览器证据保留为历史；R1 的操作链、角色/字幕与资源证据见 [R1 记录](m1-r1-review.md)，不混用旧测试通过数。当前实际 WinTTS 语音为0/11，4个机械音效不算配音。
- 待真人检查：O1 目标是否清晰、侧口发现是否自然、上下空间是否可辨、梯闩含义、移动/近门画面舒适度、提示是否过多，以及未遍历的碰撞接缝和不同设备。
- 本轮提交推送任务分支后停止，等待用户试玩反馈和本地语音试听。不得自动进入正式美术、全章叙事、S01、L02、L03、章节整合或其他章节。
