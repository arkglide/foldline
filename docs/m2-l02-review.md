# M2 — C01-L02《隔栏借物》可玩交付

2026-10-18。用户在本轮明确认可L01玩法、美术、基础氛围和角色表现，批准L02完整可玩制作。本关等待新的真人初见/综合验收；没有制作S01、S02、L03、W或整章转换。

## 运行

```sh
npm ci
npm run dev
# 对照已认可的L01：
npm run dev:l01
```

在自己的电脑浏览器打开 `http://127.0.0.1:4173`，启动播放器、点击画面。WASD/鼠标，E拿取/松手，Space跳跃，Esc暂停，R恢复本关初始检查点；V英语语音、B字幕、L简中/English字幕。完整说明在暂停页，左下无常驻操作块，左上只有标题和目标。两关保留同一项目的独立存储偏好，不随R回溯。

默认L02独立安全入口直接携带栈雀并接通固定窄门；它对应L01之后已完成的服务交接状态，**不是已经实现的连续章节入口**。北端浅门斗只结束本关，不通向一个粗糙的S02占位。

## 谜题与体验

先从玻璃外看见有把手的接驳匣。身体无法进入封闭备件隔间，也不能隔着真实玻璃选中物体。A2检修孔把视线转到备件架的侧面；孔径只有0.8×0.9m，匣子适配，1.8m高的人不适配。E取得实际穿门命中的匣子，将它沿B2→A2带回本侧。绕检修柜去宽口坞，E松手，匣子落稳后棘爪保持、继电器应答，实体出口门抬起。取走匣子不会重锁出口。

这与L01的区别是“我停留在这里，物体经连接过来”；没有增加一个先按才能借物的按钮，没有自由放门、精细插销、限时压力、任务箭头或对白解锁。观察窗、侧面折口、唯一把手物件和母线到出口的关系负责说明目标。可以忽略对白直接完成。

## 原生实现与恢复

- 固定引擎SHA：`da8ea1cf098ad99ccc89451d34bf4e272cdc15aa`；Jolt WASM。使用官方`createStaticGame`，无完整编辑器构建、引擎源码复制/修改或ZIP。

- 玩家和匣子都由`portals.watch`登记。测试记录包含真实B2→A2、A2→B2、再B2→A2；身体尝试走/跳向窄口仍留在原侧。未用触发区伪装穿门。
- 坞只检查唯一匣子：已松手、中心处于0.9×1.1m接纳范围、合适承托高度、速度小于0.18m/s，连续稳定0.3s后锁存。悬持不算、松手未落稳不算。原生门运动到开位且玩家实际越过G2才完成。
- 拿放不创建新匣子。台面/护边保留误放物；一般掉落可再拿。若物品确实掉到隔间难取位置，R明确恢复原生初始检查点并先释放旧弹簧，而不是暗中传回一个替身。没有另造“召回柄”瞬移物体。
- 暂停冻结物理/字幕并暂停播放；重试清抓取/音效、恢复机关/匣子/事件，偏好独立保留；停止走原生owner清理。

## 视觉、栈雀与声音

沿用L01的海岸设施材质和低饱和工业色：实际ambientCG混凝土/金属、原创锚柜框、托台、管线、检修母线和标识。8个静态glTF批次共1384三角形；匣子把手/护甲是其无碰撞子级视觉网格。全部来源/作者/许可/大小/SHA见[素材清单](../assets/art/l02/README.md)及manifest，没有追加大型模型包。

东高侧采光带有内凹窗框、雾面玻璃和竖梃，冷色小点光从此补层次；主体仍由检修人工照明控制。它是受控设施内部的少量外界痕迹，没有天空大厅或新的室外区域。静态顶点暖/冷光只是美术近似，未实现太阳阴影/GI；少量原生点光负责动态部件。滤镜沿用`saturate(.94) contrast(1.025)`，HUD独立，销毁恢复；无新增bloom、景深、色差或引擎后期重构。

栈雀保留已认可12mesh/5材质/1纹理，0物理体；持物、近门和贴窗时肩侧收折，不占准心。7句新英语文本延续好奇、克制幽默与衡务专业播报，使用原队列的优先级、过期/取消、一次触发和`after`回应。完整文本/触发及Windows分关卡制作见[语音说明](voice-production.md)。**本云端新英语WAV为0/7，全部待Windows生成和试听；L01本地15句认可不代表云端收到了文件。** 已有4个真实机械WAV继续用于抓取/接驳/棘爪/电机反馈；不把字幕或测试波形算配音。
