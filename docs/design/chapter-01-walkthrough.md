# 第一章首次体验推演与设计审查

**这是文档推演，不是真实游玩测试。** 没有运行 Foldline、没有输入录屏、没有盲测者或通关数据。本文从初见玩家视角检查信息与路线，暴露的风险仍需单关灰盒和用户验收。

## 正常路线的体验模拟

| 步骤/单元 | 最先看到/可能先试 | 发现与继续行动的动机 | 可能迷路/误读与反馈 |
| --- | --- | --- | --- |
| 1 S01 醒来 | 表针不稳、东侧安全扣，通风柜前有松落滤盒；先走门或按 E | 门扣与柜子的实体线指向同一个局部问题；挪盒立即看到手轮可操作 | 若以为 E 必须一直按，拿起/放下图形切换；移到任何安全处都认可，不要求精密插槽 |
| 2 S01 复压 | 试转手轮，听风声/看风条与表针；安全扣松开 | 第一次确认自己的操作改变设施；岸侧联络是接下来工作目标 | 音频未开启也能看到变化，出口不等配音；长按/重复 E 不造成反锁 |
| 3 L01 首见庭院 | 先看高处门冠，可能直奔楼梯；发现从上侧锁住 | 目标稳定、障碍可见，愿意回看侧面能操作的遮板 | 如果只看到栏杆不知目标，必须改入口构图，而不是广播报坐标 |
| 4 L01 侧面通路 | 操作遮板，看到另一侧同一梁背与出口；可能站着看或向窗探身 | “侧面就在上面”成为空间发现；迈过 A1 到 B1，视线/身体实际变化 | 若当屏幕不敢走入，边框厚度、连续地坪和脚步反馈应表达可通行；未证实其有效 |
| 5 L01 回路 | 在 B1 旁看到梯闩，开后可俯视刚才站位 | 自己留下实体退路；下一备件门开放，产生掌控感 | 不把梯闩藏成第二谜底；若玩家回去再过一次，不惩罚/关门 |
| 6 L02 看见却取不到 | 先隔玻璃 E，命中玻璃；转向窄折口看见匣子另一视角 | 已会拿放，推导“人过不去但匣子能过”；愿意试一次而不是寻找钥匙 | 玻璃要真可读；A2 与备件的关系不能靠同色小灯猜；卡口应视作布局/力问题 |
| 7 L02 取匣接通 | E 拉回，走到宽坞松手；棘爪落位，门开；远处电机响 | 一个明确成功与一个令人不安的远处变化同时发生；继续去回廊而非被锁着看演出 | 玩家可能只顾庆祝而漏看 W；不能据此判剧情失败，S02 会留下可再观察的后果 |
| 8 S02 回到后果 | 沿坡下到低处，自己打开百叶，看到同编号卷闸/电缆背面 | 回忆刚才的动作，产生“维护线为何被隔离”的疑问；敲击/灯闪促使靠近 | 不要求立即判断有人，也不播放真相长独白；权限柄给明确继续方向，旁路只作为可选局部改善 |
| 9 S02 小介入 | 可能试手摇补气；风条和局部灯恢复，卷闸仍锁着 | 操作有用但不是完全解决，留下继续核查的动机；拨权限柄解锁工具柜 | 若误以为补气已完成救援，局部变化与仍锁卷闸要同框；广播可短澄清，不替代现场 |
| 10 L03 低处新目标 | 取工具，先见高处门冠、近端锚位和上行检视坡道；可能试着直接瞄高处 | 低处受实体挡屏遮挡；新工具的预览提示可用锚位，促使换观察位置 | 若到处射击碰运气，说明锚面视觉语法/预览不足；不增加可射面噪声来延长探索 |
| 11 L03 留端点 | 高处看见 B3，先/后放一端；发现需要回到低处另一端出发 | 顿悟在于“看见处与出发处分离，连接仍保留”，不是记住按键顺序 | 可能觉得回坡道是无效跑腿；门冠、近端实线和已放端点反馈要维持目标，坡道保持短而安全 |
| 12 L03 抵达联络台 | 从 A3 出 B3，回望 Q 和入口，操作联络柄 | 自主完成空间连接，理解站内修复仍有更大去向；通往眺台的门打开 | 若重配把自己困在上台，实体下侧返回/重试和半穿越保护必须可靠；不能强制照预期顺序 |
| 13 S03 下一任务 | 看到主线灯和低处暗区，操作机械指示柄，接收臂未到位 | 明白通信已通但运输尚未可用，下一工作来自设施目标，不靠章节字幕 | 如果把低区当马上要跳下的目的地，栏杆、闸的实物线与指示构图要修；不把迷路算探索时长 |

上述步骤没有给出实测分钟数。18～26 分钟来自容量假设，不把每个行为硬性延时成预算。

## 反向尝试与设计应答

| 初见玩家可能做的事 | 当前设计应答 | 仍未被验证的风险 |
| --- | --- | --- |
| 不信广播，先乱走 | 主目标来自门/表针/物理线路；语音不是解锁前提 | 是否能真正无声理解；需静音初见测试 |
| 把滤盒带过所有区域 | 允许保留；不能当唯一匣误锁存，也不被静默销毁 | 垫脚或堵门的组合可能形成有效旁路；要实际测 |
| 不知道折口可以走 | 连续地坪、另一侧空间/脚步、宽框与目标关系 | 不能只凭作者认为明显；需观察首次穿越前的犹豫 |
| 尝试身体挤 A2 | 真实孔径拒绝，狭窄托台与物件尺寸提供反例 | 阻挡不能像不可见门禁；相机贴近不能闪烁 |
| 只按了 D 没有松手 | 棘爪不落、承托片可见，松手标记出现 | 弹簧抖动/物件朝向可能造成虚假失败；应加容差/改托架 |
| 给 W 塞东西/门前发呆 | 早期固定机械护网保护扫掠区，仍有原生堵门停障合同 | 任何可达漏洞不能由强删物件修剧情；异常状态必须诚实播报/保存 |
| 漏看供电导致的封闭 | S02 相反观察方向、同编号与电缆、可选气路提供两次物理证据 | 仍可能认为是随机美术变化；要询问玩家因果理解 |
| L03 先放 B3 再放 A3 | 完全接受，结束条件不限定顺序 | 提示和任务文字必须同样中立，不暗示唯一按键序 |
| 从 Q 跳去联络台 | 6m 以上分隔和挡屏/护罩初步限制，落下仍可回路 | 跳跃/抱匣/惯性组合未知；可接受有价值替代解或改真实几何 |
| 放端点时瞄得过高 | 第一章校准锚位，预览安全门位 | 游戏层校准必须仍通过真实 raycast/遮挡，不可隔墙选框 |
| 回到第一关时旧折口已休眠 | 实体返回梯始终在，路径可回访 | 安全交接、物品 path 与读档状态必须真实一致 |
| 频繁重试、关页面再继续 | 世界与事件旗标一起回溯，已消费广播不重复，未播按相关性恢复 | provider 生命周期、存储配额和中断状态未实机验证 |

## 推演中发现并已反映在设计的修订

这些是**文档修订**，不声称修复了运行中的 bug。

| 发现的问题 | 已采用的设计修订 | 对后续验证的影响 |
| --- | --- | --- |
| 一开始就自由放门、取物和讲故事，注意力过多 | L01 固定通行，L02 固定窄口取物，L03 才自主放两端 | 需验证教学总量是否仍过密，不因拆成三关就默认成功 |
| 跨门取物若没有普通拿放先修，会同时教按键和空间规则 | S01 增加挪开滤盒的直接操作，不要求精密匹配 | 看玩家到 L02 是否真的会 E 拿放，而非只转过阀轮 |
| 切服务对会让老区域变成孤岛，尤其玩家返回时 | L01 上侧先开实体返回梯；旧对无半穿越才能交接 | 复位/回访/持物跨界需单独验证，不能只测向前通关 |
| 玩家只看 G2 门开，可能错过自己造成的卷闸封闭 | S02 必经百叶提供同一装置背面，补气可实际改变局部状态 | 问玩家变化由谁触发；程序打开百叶不代表已理解 |
| 一个高空横梁不能保证挡住下层视线 | L03 改成从地面起的 3.8m 实体设备挡屏，明确下部护罩和高处检视口 | 示例视线算式只覆盖代表点，灰盒需遍历全走区/边角视线 |
| 第一次自主放置若过高会让玩家怀疑穿越规则 | L03 校准锚位给安全中心，真实 raycast 仍校验遮挡；微调留后续 | 确认辅助不隔墙激活，不以“吸附”掩盖错误碰撞 |
| 把 A 后 B 当唯一顺序会否认合理发现 | 接受任意端点身份、任意放置顺序和等价高观察点 | 自动检查不得写死顺序；真实测试要主动尝试反向解 |
| 上层重配折口后可能失去返回路；S02 坡道若太靠北还会侵入上层眺台净高 | T 同时解锁实体返回梯下门，梯舱外壳保持解题前遮挡；S02 横坡北侧边界收在 Z≈28.2，眺台从 Z=30 开始 | 验证完整三维净高、梯舱南侧绕行和不依赖门的返回，不只审看平面图 |
| 单看计时器会把堵住的 W 误判为“已闭合” | 请求/运动/到位/阻挡分离，blocked 与 closed 台词和存档不同 | 验证真实 pose 和清障后恢复，不先播结果 |
| 为故事锁头/等配音会阻碍解谜且填充时长 | 门由设备状态开；短广播随行，漏听可由环境理解 | 静音/跑过演出仍可推进，另评估叙事可读性 |

## 下一阶段真实验证计划（未执行）

先请求对 **C01-L01 一个单元**的设计/灰盒阶段批准，其他单元保持文档状态。后续逐关遵循[七阶段制度](../production-and-acceptance.md)，不同时造六单元来测试整章。

- 技术：真实胶囊/眼高、近门渲染、原生穿越/回望、固定楼梯、门到位和 R 重试；不要用控制台瞬移冒充可通行路线。
- 初见理解：记录是否先看见上层目标、如何发现侧面路径、能否描述空间关系、有没有把折口当屏幕；作者不出声带路。
- 非预期：直接走梯、跳栏、带滤盒、反向穿越、暂停/失焦、回旧检查点；接受合理探索，阻塞则回退设计。
- 后续 L02 批准时再验证窄口/抓取/坞座与剧情因果；L03 批准时再验证所有观察角、放置顺序和捷径；不提前搭它们的测试关卡。
- 记录独立测试者是否读过解法。模型推演、作者按剧本通关、引擎单测、自动化输入、初见玩家和用户最终验收，分别标注。

## 本轮结论

第一章形成了可供审查的连贯空间、机制先修、操作后果和异常恢复方案；推演暴露的问题已在文档中修订。仍有未验证风险，因此本篇只能称“设计推演”，不能称“体验已合格”或“关卡已完成”。M0 原停止点已由用户本轮的 L01 灰盒授权更新；M1 实际布局、真实输入自动化证据与未验证体验见 [L01 灰盒记录](../m1-c01-l01.md)，不能把该技术验证当作本篇第一章全流程已经过试玩。
