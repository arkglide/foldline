# 九章路线图与单元候选

M0 提案，**仅 C01 进入详细设计**。C02–C09 的单元只确定设计价值、先修与目标；没有房间坐标、实现任务或制作授权。34 个核心谜题候选可随试玩删改。

ID：`Cxx-Lxx` 为独立谜题；`Cxx-Sxx` 为互动探索/剧情序列。章节容纳多个单元，单元可包含多个房间。机制代码见[递进图](mechanic-progression.md)。

## C01《苏醒》——先知道自己改动了什么

- 剧情目标：复压、取得接驳权限，接通岸侧联络；亲眼见到供电同时封闭了低处维护线。
- 玩家认知/动机：知道自己的检修身份，相信正常复位能开出站路径；离站动机清楚，初步怀疑“恢复”的对象。
- 机制：F0 基础交互；F1 固定折口到自主放置；F2 跨门取物；F5 只教锁存坞，不教保持式或计时。
- 单元与衔接：`S01 → L01 → L02 → S02 → L03 → S03`。低处起步→上层通行→回廊下探→调度厅回望，最后通过同一设施的联络闸进入 C02。

| 单元 | 独立设计价值 / 新认识 | 目标与结束条件 |
| --- | --- | --- |
| C01-S01 复压值守室 | 操作可改变风声、表针和出口状态，建立场景反馈语法 | 手动通气达到安全读数，走出值守室；不等长配音 |
| C01-L01 侧向通行 | 看到的高处出口，可从侧面的固定折口抵达；空间不等于平面距离 | 从上侧释放实体返回梯闩并通过出口 |
| C01-L02 隔栏借物 | 身体无法通过的折口仍可成为物体通路；抓取依照折线路径 | 取回接驳匣并让锁存坞接通，出口到位 |
| C01-S02 卷闸背面 | 把“接通”的广播与自己造成的封闭现场对照；可手摇补气 | 检视新封卷闸和旁路，取得接驳器权限并进入调度厅 |
| C01-L03 回望接驳 | 观察位置与出发位置可分离，端点保留使绕行产生意义 | 自主放置一对端点，抵达上层联络柄并接通 |
| C01-S03 候潮眺台 | 对比主线启动与维护线熄灯，下一目标来自现场 | 手动调出岸侧机械指示，穿过已解锁的备件层闸 |

节奏：短的操作发现→首个空间顿悟→较慢的取物试验→可互动的安静回望→自主接驳→展开设施视野。详见[空间设计](chapter-01-awakening.md)与[事件设计](chapter-01-events.md)。

## C02《借来的手》——取回来，还是留在那里

- 剧情目标：为岸侧联络准备实际供给，第一次发现回收某物会撤掉别人的通路。
- 认知/动机：相信自己能解决局部故障，想用接驳器走捷径；开始考虑供给的去向。
- 机制：F2 路径/转角/保留端点深化；F5 引入**保持坞**，在安全地面看清“移开就撤销”，与锁存坞形状/回弹声区分。
- 环境：围绕同一配货中庭的斜列货架、落地回收区与双侧作业台，不是四个箱子压板房。

| 谜题 | 独特问题；与前关的差别 | 结束条件 |
| --- | --- | --- |
| C02-L01 背面收件 | 从真实玻璃后看到物资，再从侧面折口沿转角取件；直线可见不等于可达 | 取件入本侧锁存坞，开放货架背面实体路 |
| C02-L02 留在对岸 | 已学“取回”，现在匣子应留在远端保持坞，玩家才能乘平台；失供只落到安全托台 | 玩家与匣子分处正确两侧，平台抵达有实体退路的落点 |
| C02-L03 转角的距离 | 最近的屏幕距离反而是最差搬运路线；改锚面才能避免实际路径受阻 | 匣子沿无阻路径抵达收件台，未穿墙、未绕过碰撞 |
| C02-L04 收回通路 | 唯一匣子支撑当前通行，先建立实体备用路再回收，不能一路拖走 | 匣子可带走且两端均保留不依赖它的离开路径 |

序列：**C02-S01 退件台**，翻开退件机构发现“空载”标签与反复补修不符，可手动送回一件滞留物；**C02-S02 货架背脊**，从已开的背面路调整检修照明，观察主线与维护线接收不同物资。

节奏/衔接：先熟悉取物，再把同一行为反过来；两个局部维护间歇拆开抽象约束。C01 的联络请求变为真实货物任务，末端实体栈桥接入 C03 货井。

## C03《高处的近路》——高度也是一种资源

- 剧情目标：沿损坏的立体货井抵达校验层，看到整站上下层的交通差别。
- 认知/动机：懂得保留退路，但仍主要按走路距离思考；想借旧物流设施越过停运升降段。
- 机制：F3 先用低落差/宽接收区理解动量转换，保留 F1/F2；不引入任意重力或极窄反应窗口。
- 环境变化：相同货井从不同标高被反复看见，主线总在上层，维修人行路贴近回水层。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C03-L01 落差尺 | 以备件试送和接收挡板读出落差效果，选择足够而非最大的高度 | 玩家落在近侧宽平台并能沿实体梯返回 |
| C03-L02 越过回收层 | 高出发点会越过目标；借锚面高度与路径选择获得合适落点 | 抵达中层检修台，不依靠碰撞弹飞或瞬移 |
| C03-L03 反向投递 | 物体和人需要不同终点：先把匣子送到高位回收篮，自己走低速路线 | 回收篮供给接通，玩家从另一条已见路线到达 |
| C03-L04 同井两程 | 一口井承担两次方向不同的旅程，先前落脚点变为第二程的观察位 | 完成上层交通交接，保留可返回下层的实体回路 |

序列：**C03-S01 潮痕层**，手摇排开观察窗前的积尘，读取新旧潮痕与维护脚印；**C03-S02 检查吊篮**，沿已停稳的吊篮检查实际受损线缆，拨开标识罩看见维护区仍有受电迹象。

节奏/衔接：四次推理改变高度用途，不四次加大跳距；危险失败短重试。上承 C02 保留退路的习惯，下接 C04“标签是否真的对应所见线路”的核查动机。精确落差在该关获批灰盒前不承诺。

## C04《偏航之光》——读数也有朝向

- 剧情目标：校验“维护区空载”的报告与真实负荷；让广播首次承认记录冲突。
- 认知/动机：已有可疑现场，尚不能确定是故障还是错误对象；主动去验证，而非等终端揭密。
- 机制：F4 无伤害校验束、反射与跨门视角；与 F2、F5 组合。可见束是查询的表现，不自动造成伤害。
- 环境：折线形校验廊、不同朝向的仪表背板、可绕看的中庭；建筑遮挡和观测点决定推理。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C04-L01 光斑的背面 | 接收器朝向背对入口，必须从另一视角确认有效入射，不能凭灯色猜 | 用反射送达真实接收面，校验臂解锁 |
| C04-L02 不在手边的读数 | 调节位与可读位分离；用已学跨门观察保留反馈，再调整反射台 | 稳定读数进入有效区并锁存，不要求盲调或快速来回跑 |
| C04-L03 照明与承重 | 同一束校验只服务一个目标，先锁住机械托架再移交光路 | 托架保持，另一支线完成校验，玩家能安全离开 |
| C04-L04 遮住的出口 | 主动遮断已读完的光路以解除错误隔离，认识“没有信号”也是状态 | 从现场确认维护负荷，解除通往夹层的隔离联锁 |

序列：**C04-S01 对号台**，揭开可动标签架，把读数接头与真实去向对照；**C04-S02 静音检修廊**，关闭误响蜂鸣器后听到真实管道敲击，并打开通向 C05 的检修口。

节奏/衔接：稳定、安静的观察推理替换 C03 的运动；末段只复用已教过的遮断反馈。上承负荷线索，下接现场求证；没有“读一份日志便知道全部真相”。

## C05《封闭线以内》——回到自己造成的结果

- 剧情目标：到达第一章卷闸内侧，接通许澈与撤离路径，理解旧登记的缺口。
- 认知/动机：知道报告对象错误，愿意修复自己的操作后果；对广播保持核查而非全盘拒绝。
- 机制：F1/F2/F4/F5 在背面、低净空和回访环境重组；本章不给新工具，形成叙事与认知停顿。
- 环境变化：同一卷闸、电缆与潮痕编号与 C01 对上；可选补气状态在这里有可见回报，但不决定生死或结局资格。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C05-L01 门闩的另一侧 | 维护侧没有主线控制台，沿已见机械结构找到可操作的背面联锁 | 解除一段侧闩，形成不依赖广播的实体路 |
| C05-L02 先留一条人行路 | 回收供能匣会截断维护者的离开路线；先改变远端通路再移交物资 | 维护线出现连续安全通路，物资也能回收 |
| C05-L03 两个读数 | 风压表与供电灯不代表同一件事，结合光路和阀位确认真正补气 | 供气/排出两端均满足离散安全条件，门允许操作 |
| C05-L04 回到那扇窗 | 从背面解开 C01 的封闭机构，旧障碍变成跨区域捷径 | 原卷闸开启、旧观测点与维护层连通，现场状态写入进度 |

序列：**C05-S01 有人值守**，通过玻璃进行简短手势/短程联络，玩家先开传物槽再交换一件维修件；**C05-S02 双面通道**，回看原窗与已开启卷闸，亲手更换误导性的安全标识。

节奏/衔接：较少抽象新知识，以不同侧面的操作和回访兑现悬念；人物不通过长对白阻挡通行。上承校验结论，下接恢复多条路径的实际责任。NPC 寻路不是此计划的先决 API；人员移交表现和通路状态需在本章详设时确认。

## C06《承载》——自己站着的路也会被撤掉

- 剧情目标：建立从维护层到主物流层的可靠维修通道，看到临时恢复的代价。
- 认知/动机：懂得纠正局部隔离，但必须让人的脚下也有路；不再只看设备的绿灯。
- 机制：F6 凸截面承载投射；先在安全地面看清有限宽度和遮挡，再与 F1/F5 组合；不引入流体或软体。
- 环境：错层实体落台、穿柱维修架和能回望的横井。承载路径采用本作层页/肋条语言，避免复制原作道具外观。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C06-L01 脚下的路径 | 看得到中心线不代表脚下有足够宽度；先从侧面确认真实截面 | 生成连续可承载段并走到实心落台 |
| C06-L02 留出的转身处 | 墙柱从侧边截断有限体积，需调整锚面和方向留出实际净空 | 人与匣子均能通过，不以无碰撞视觉桥冒充成功 |
| C06-L03 承载者不能撤路 | 站在投射上不能安全换掉它；先抵达实心中继台再重配端点 | 在安全台完成换路，原路撤回不导致不可恢复坠落 |
| C06-L04 同一处两次落脚 | 唯一一对折口先服务运件、后服务人行，先前落台成为换路工作位 | 两种任务交接完成，末端留下永久实体保险路 |

序列：**C06-S01 裂缝观察架**，手动展开非承重检视板，观察临时结构受力标记；**C06-S02 老扶手**，检修实体保险路的卡闩，让后续回访少一次折口操作。

节奏/衔接：先慢观察、再局部紧张、再回到稳态；不以持续坠落消耗时长。上承维护层的责任，下接 C07 人/货路径不同的调度需求。投射碰撞和撤路安全为本章独立技术门。

## C07《缓行货流》——货能通过，人未必能

- 剧情目标：让受阻补给重新流动，同时保持维护人行通路；许澈从求助者成为现场协作者。
- 认知/动机：有基本安全网络，希望恢复有用的供给而不重复封闭维护线。
- 机制：F7 定向货物流，先只作用于货物；与 F2/F5/F6 组合。货流方向、截面与段落都可观察；没有乘风猜路的新手惩罚。
- 环境变化：倾斜卸料台、不同高度的停货器、交错的人行侧桥；运行声出现但不变成必须抢秒的流水线。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C07-L01 看见运力 | 匣子受牵引，人不受牵引；货的停靠点由阻挡和方向决定 | 一件物资安全到达可回收停靠位 |
| C07-L02 逆送取件 | 默认货流把必要物件送离玩家；在稳定停货状态反向或重定向一段 | 必需件回到可抓取位置，未形成无限往返循环 |
| C07-L03 出口不在箭头上 | 跨门后方向随段变换，不是继续沿原世界方向；需从落点反推连接 | 货物沿折线抵达远端保持坞，承载路维持 |
| C07-L04 货过，人留 | 货路占用一对端点，人必须沿先建实体/承载路离开，不能追着货走 | 补给到达且人行出口安全，卸载后能回收临时路 |

序列：**C07-S01 封住的收件窗**，手动打开被误封的支线收件槽，亲眼见到维护侧收走物资；**C07-S02 降速台**，调整停货器让物资安全停靠，对照“满速”指示与实际安全性。

节奏/衔接：运输观察与静止状态推理交替，不用无意义等货；提供可暂停/召回的尝试。上承人行安全，下接 C08 的多区资源交接。运行中的实际 field 过滤、加速与停靠须另行验证，M0 不宣称已可玩。

## C08《重写接驳》——把局部解法变成可交接的网络

- 剧情目标：为最终恢复决定提供三套真实可用的回路，补齐现场登记而非推翻一台人格机器。
- 认知/动机：理解广播不全知，也理解维护线和主线都需要资源；想留下可持续的方案。
- 机制：不新增底层能力；F1–F7 组合为 F8 多路交接、独立旁路和撤销安全。第九章需要的操作在这里无时压地练过。
- 环境变化：同一中枢从不同区间环绕，读数由玩家验证后逐段可靠；保持有空白、有安静工作位。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C08-L01 保通底账 | 按物理去向而非标签重接一条供给，核查到底保住谁的路 | 一条主线与对应维护支线的真实状态同时可见 |
| C08-L02 两端见证 | 一对端点无法同时承担两处持续供给，需用实体旁路解除互斥 | 两处安全状态同时成立，端点可供下一任务使用 |
| C08-L03 独立回路 | 把曾依赖中央读数的支线变成可就地验证、可手工隔离的回路 | 三种最终方案所需的独立安全条件均已演示并登记 |
| C08-L04 空载回收 | 从终态倒推撤除临时件的次序；打开所有门并不等于安全完成 | 临时路收回，已开放的人行/必要供给不被误切 |

序列：**C08-S01 对照步道**，实际走到两个已修支线的观察位，操作指示罩核对主线/维护状态；**C08-S02 三路交接图**，分别接入试示柄，使三方案的去向和代价在设施上短暂显示，但不提交最终选择。

节奏/衔接：复杂综合题中间安排安静核查，避免连续四个大题疲劳。接续货流成果，末段进入 C09 岸侧交接庭；必要事实在主线上出现，不把共管结局锁在收藏品背后。

## C09《折径》——亲手承担最后的去向

- 剧情目标：做出知情恢复决定，走过它实际造成的终态，完成人物弧线。
- 认知/动机：知道三条路都可行，也知道它们不能无代价地同时存在；希望清楚交接责任。
- 机制：纯复用 F1–F8；无末分钟新机关、首领战、记忆测验或隐藏限时题。
- 环境：能同时观察岸侧装载、实体撤离口与维护岗位的交接庭，三条选择是可走、可看的空间关系。

| 谜题 | 独特问题；新增空间关系 | 结束条件 |
| --- | --- | --- |
| C09-L01 只剩一对 | 先用宽落台的低风险试送唤回落差知识，再在一对端点的资源约束下选择临时路线，看到其会占用什么 | 人和必需物资抵达交接平台，未关闭最后实体退路 |
| C09-L02 交接前的最后一程 | 接驳许澈侧的维修件并完成两侧安全确认，清楚区分远端信号与人的到位 | 维护人员撤离/值守条件就绪，选择点检查点有效 |
| C09-L03 承担去向 | 按 E-A/E-B/E-C 之一实际建立最终回路，再单独确认，不靠菜单魔法改变设施 | 唯一方案转换到位，写入结果，开放对应尾声路线 |

序列：**C09-S01 交接前庭**，在安全区走看各方案的物资/人行后果，短询问可选且不提供谜底；**C09-S02[A/B/C] 终态尾声**，执行[三个结局](game-architecture.md)对应的最后交接/步行/轮值操作。互斥尾声只计一个序列位置。

节奏/衔接：先回望，再有知情但不抢秒的最终操作，最后留足观察与收束时间；三个结局都结束完整流程。重放从选择检查点开始，不用填充关卡惩罚好奇心。

## 候选取舍规则

某候选若不能产生独立新认识、需靠文字解释机关摆放、与前关只是数量差异，或实现依赖未支持能力，则合并、重排或删除。章节时长降低时先审查设计价值，不补空房。下一轮只允许详设获批准的单元，不逐条实现本表。
