# 第一章事件、广播与恢复合同

M0 的正式章节事件合同，不是已实现的状态机。M1 仅实现 L01 的遮板/固定折口/上侧梯闩/完成与入口重试子集；完整广播、章节检查点及其他单元未制作，实际差异见 [L01 灰盒记录](../m1-c01-l01.md)。坐标/物件见[空间设计](chapter-01-awakening.md)。状态必须对应实际世界；按按钮、发指令、机构到位和玩家理解是四件不同的事。

## 关键状态与持有者

| 状态 / 稳定对象 | 语义和恢复责任 |
| --- | --- |
| `ventSafe` | 通风柜滤盒已挪开，手轮完成安全复压；S01 的安全扣可用 |
| `returnStairOpen` | L01 上侧梯闩实际到位；切走 A1/B1 前的实体返回路前提 |
| `servicePair` | `court / parts / portable`；全章至多一对活动折口，未链接的便携端点不算额外服务对 |
| `busCommissioned` | L02 匣子已松手、稳定入坞并锁存；恢复源值/棘爪，不因后来拿走匣子而回退 |
| `isolationCommanded` | 供电已发出 W 隔离请求，不表示 W 已闭合 |
| `shutterPhase` | `raised / closing / closed / blocked`；由真实运动/占用决定，保存运动进度/目标，禁止固定延时猜到位 |
| `inspectionBlindOpened` | S02 检视百叶已打开，作为打开观察机会的状态，不代表玩家真的看懂 |
| `airBypassOpened` | 可选手摇补气状态；改变局部风条/灯，C05 兑现；不绑定结局资格 |
| `toolPermission / toolAcquired` | 权限拨柄与实际取工具是不同动作；取工具后方可放便携折口 |
| `contactConnected` | L03 上层联络柄实际到位，不能由靠近高台区域代替 |
| `routeIndicatorSet` | S03 玩家操作机械指示柄，明确接收端缺口，允许下一闸松开 |
| `announcementConsumed` / 待播 ID | 有限广播旗标/短队列；保存 ID，不保存音频句柄/Promise；读档后不自动重播已完成广播 |
| `c01.parts.crate` / `c01.vent.filter` | 唯一物件稳定 ID；物理状态与归属随引擎/游戏 provider 保存，召回不复制 |
| A1/B1、A2/B2、A3/B3 与各门/平台 | 稳定局部节点/portal ID；内置保存世界/门拓扑，游戏保存服务对和规则。不能只保存布尔胜利旗标 |

提案 provider：`foldline.story`（版本化章节/剧情后果）和 `foldline.c01`（版本化本章规则）。恢复时核查版本与节点拓扑，不静默丢掉旧字段；不在加载中 capture。机关源与动态反馈由 provider 重建，触发区域在下一完整固定步重新采样；完成之前不开放输入。

可选的“看过 W / 从哪里到达高台”只作为诊断/提示依据，不能当作知道玩家内心的变量，也不能用看过特定像素强制过关。

## 事件与真实触发

| ID | 触发前提/玩家动作 | 实际变化与成功反馈 | 防重入/非预期行为 |
| --- | --- | --- | --- |
| EV01 | S01 滤盒挪离操作口，空手 E 操作手轮，安全读数到位 | 设置 ventSafe，安全扣松开；表针/风条/出风声同步 | 稳定状态锁存；重复 E 不重新关门；不能只碰阀轮就计完成 |
| EV02 | L01 操作手柄，源/目标落脚安全且场景准备好 | 遮板收起，A1/B1 成对启用 | 旧状态相同则无重复；表面/孔径失败不假装已启用 |
| EV03 | 上侧梯闩实际拨开 | returnStairOpen，解锁上层出口；实体楼梯可双向走 | 不要求特定脚步/折口 ID 才承认抵达；记录绕行待审查 |
| EV04 | L02 入口选择柄，returnStairOpen=true，旧对边界无 traveler/持物路径 | 旧对休眠，A2/B2 启用，servicePair=parts | 未安全时保持旧对/旧状态，提示清空边界；不销毁墙让玩家漏下去 |
| EV05 | 唯一匣在 D，已松手，速度低且稳定约 0.3 秒 | busCommissioned 锁存；G2 开门请求；isolationCommanded；W 安全闭合请求 | 过滤玩家/装饰/错误物；同一锁存只发一次；棘爪到位有非颜色反馈 |
| EV06 | W 原生运动抵达闭位，或扫掠/占用发现障碍 | 分别进入 closed/blocked；闭位才报“归位”，阻挡则停住/安全退让并告警 | 被挡不致死、不强制移除阻挡物、不伪造 closed；不影响已打开的 G2 |
| EV07 | S02 打开百叶、拨权限柄；补气另为可选动作 | 允许查看 W 背面；登记权限；旁路改变风条/局部维护灯 | 看过百叶不等于已理解剧情；旁路不解锁隐藏结局、不惩罚未选者 |
| EV08 | L03 空手操作已授权工具柜，旧对边界安全 | 工具入手；servicePair=portable；显示端点输入；A2/B2 安全休眠 | 旧对有半穿越则暂不交接，可退回整理/复位；没有物件在未知空间被销毁 |
| EV09 | 玩家在上层实际操作 T | contactConnected；上层出口与实体返回检修梯下门解锁，实际到位再放行；显示岸侧尚未完成的接收端 | 合法替代路线抵达同样有效；不以是否使用作者指定门序决定成功；上层失去折口后仍能返回 |
| EV10 | S03 去向柄到位、下一闸到位，玩家穿过安全阈值 | routeIndicatorSet 后的章末交接；未来先保留有效 C01 存档，再加载 C02 | 边界内禁止多次加载；失败留安全原场景；M0 不实现此逻辑/下一章 |

门/卷闸通用规则：先按真实形状检查路径与占用，再进行运动；运动中再次检测，受阻暂停/退回安全方向。遮挡清除后允许继续，不能依赖广播结束推进。可见状态到位才放行；如果逻辑命令与实际状态不符，HUD 只报未到位，不先给成功音效。

## 第一章必要广播

广播短、不中断控制，字幕可读；**没有一扇门等待广播播放完毕**。新谜题操作反馈优先于叙事声音，同一时刻最多一条必要语音，过时队列可以丢弃并依靠环境信息，不积累到下一关长播。

| ID/条件 | 必要台词提案 | 叙事/引导目的与限制 |
| --- | --- | --- |
| B01，初次取得输入，现场已可观察 | “值守席，先确认通气。岸侧联络尚未接通。” | 告知现场目标，不播身份和历史长介绍；未解锁音频先字幕 |
| B02，EV02 成对启用完成 | “巡检折口已接通。两端落脚区正常。” | 告诉设备状态，不说明走哪条路线 |
| B03，EV03 梯闩到位 | “返回梯已解锁。备件侧允许接驳。” | 确认实体退路与下一功能区，不抢第一次过门时的观察 |
| B04，EV05 已锁存 | “检修供电已接通。维护线进入空载隔离。” | 使用旧登记语言；与现场隔离后果发生联系，不宣称隔离已完成 |
| B05a，EV06 真实 closed | “隔离卷闸归位。” | 只在实际到位时播；与下行低频声分开 |
| B05b，EV06 blocked，替代 B05a | “隔离未到位。请勿进入运动区域。” | 真实反映阻挡；移开后到位只补最终确认，不循环刷警报 |
| B06，EV07 权限登记，玩家已能观察 W | “维护线为登记空载区。岸侧联络优先。” | 维持规则/现场的张力；不提前宣布完整真相；C04 才核查登记错误 |
| B07，EV09 联络实际接通 | “岸侧联络已通。现场接收仍未到位。” | 区分报告通信与运输可用；不给下一谜题解法 |
| B08，S03 去向柄到位 | “岸侧接收臂未锁定。请从备件层接驳。” | 玩家先操作/观察，广播补充下一目标 |

常规路线为八条短播报，B05 的两个变体不会同时作为两段完整叙事播放。必要台词总量控制在约两百汉字以内的量级，演出节奏仍需实际测量，不用朗读时长补游戏时长。

可选补气反馈：“旁路通气已建立，未解除维护隔离。”可以只用机械反馈和字幕；不能让玩家误以为已救出维护线。敲击字幕为“隔墙传来三下轻敲”，不替玩家作“广播说谎”的结论。

## 提示层级提案

启用辅助或主动请求才给显式提示。环境指向性可在闲置时轻微增强，但不覆盖必要设备音。初始 45～90 秒的卡住判断只用于收集/调参，不是已测好的通关阈值。

| 单元 | 第一层：对象 | 第二层：关系 | 主动要求明确解法时 |
| --- | --- | --- | --- |
| S01 | 通风柜把手/宽托盘轮廓 | 先挪开挡住手轮的物件，不必精准摆回 | 说明 E 拿起/再次放下，再空手操作 |
| L01 | 已抬遮板后的视窗和高处门冠 | 梯闩的可操作面位于上层；比较窗口里的梁背 | 指明固定折口通行并从上侧开闩 |
| L02 | A2 边框回应、匣子把手 | 检修通路尺寸容得下匣子；真实玻璃挡着直线 | 指明透过 A2 抓、退回本侧、松手放入 D |
| S02 | 检视百叶与风条 | 对照同编号卷闸和已接通的电缆，旁路只改变通气 | 指明权限柄；补气保持可选 |
| L03 | 西侧坡道观察口、近端锚位 | 高处可以看清远端；已放端点不会因离开视线消失 | 给出两端任意顺序放置、回下层过门的步骤 |
| S03 | 机械去向柄与下一闸实物线 | 联络不等于接收完成 | 指明操作去向柄后去东侧接驳闸 |

如果玩家已经理解却多次失败，优先记录手感/碰撞缺陷，不叠加提示。如果一项显式提示承担了本应由环境表达的核心线索，回退修改空间。

## 检查点及重试

坐标为脚底安全出生位；恢复时清空移动愿望/待跳跃，归零不合理残余速度，释放鼠标并允许一次用户手势重新锁定。首个点击只恢复控制，不意外触发 E/放门。正常玩法中不任意清除玩家动量。

| 检查点 | 安全位置 / 朝向目标 | 保存的关键条件与恢复内容 |
| --- | --- | --- |
| CP01-entry | (2,0,1.5)，看通风柜/出口 | 初始物件、通气未完、开场播报状态；唯一滤盒 |
| CP02-court | (9,0,3)，看上层门冠 | ventSafe；L01 未解；滤盒按实际安全归属保存 |
| CP03-parts | (25,2.4,12)，看备件作业面 | returnStairOpen；尚未接通 D；服务对按入口实际状态保存，不能假定已按 EV04 |
| CP04-after-power | (29,2.4,24)，看回廊 | busCommissioned、G2 到位；W 当前真实进度/closed/blocked、已播与待播旗标 |
| CP05-dispatch | (14,0,24)，看近端/高门冠 | 百叶/权限、可选补气、工具已取、安全交接 portable；两端按当时状态恢复 |
| CP06-chapter-exit | (25,3,33)，仍在第一章安全侧 | contactConnected、routeIndicatorSet、完整本章状态；后续加载失败可回此处 |

保存仅在非关卡切换、玩家不半穿越、机构稳定或进度可恢复、必需物状态可恢复时进行。若仍持物/正在换对，待稳定再写，不强制把物件从手中拿走；保留上一有效检查点，不能假报已保存。持久写入失败须有明确失败/重试提示，可保留已捕获的会话快照用于本次 R 重试，但不声称已可跨会话继续。

R 的提示应说明回到哪个检查点，会撤销该点之后的操作。读较早检查点时，世界变化、剧情旗标与已播记录一起回溯；不要保留未来真相却恢复过去设备，或永久抑制重玩时应发生的事件。正常加载当前点不重复播已消费行。

恢复建议合同：验证 provider 版本与稳定 ID → 等待正确关卡加载 → 引擎恢复原生物理/门/关节 → 游戏恢复源值、锁存、工具和反馈 → flush → 重新采样触发器 → 确认出生位安全 → 允许输入。任何阶段失败报告错误并保留/退回有效状态，不能让玩家在黑屏中永久等待。

## 故障/滥用矩阵

| 情况 | 玩家应看到/能做什么 | 验证重点 |
| --- | --- | --- |
| 射线穿过玻璃或 `truncated` | 不抓/不放，保留旧状态，显示阻挡/范围反馈 | 物理命中、总射程、路径和预算，不用屏幕距离绕过规则 |
| 匣子丢到窄口后侧/不可达处 | 回收柄可召回同一匣；失败则 R 到本关有效点 | 不复制、不吞物、不因重试重播全部广播 |
| 物体半穿越时切服务对 | 保持旧对，提示清空边界；能松手整理 | 抓取 path 更新、`active` 检查、门关闭退让；不能整墙禁碰 |
| 堵住 G2 或 W | 停住/退回安全方向，反馈未到位 | 物理占用与 motion 目标分离；不要压死、穿模或假完成 |
| 抱匣压 D、快速拿放 | 仅静置松手稳定一次后锁存 | 去抖与唯一件过滤；不靠每帧事件堆叠多次触发 |
| 打开百叶后立即跑开/静音 | 主线仍可进行；物理证据留在现场且可回访 | 不强制注视、读文字/听满语音不是结束条件；另记录理解是否发生 |
| 换端点失败/同面重叠 | 失败不移动旧门，可继续调整/重试 | 游戏锚位逻辑不能绕过引擎拒绝；不销毁原连接 |
| 合法捷径抵达上层 | 能操作 T，记录为替代解供审查 | 不以隐形路线标志惩罚探索；设计需要时回退修改真实结构 |
| 页面隐藏/暂停/失焦 | 自动释放锁，不偷偷放门；机构使用模拟时钟 | 回来一次点击恢复，输入边沿不重放，动作不在后台堆积 |
| CP 写入失败/版本不符 | 显示失败，保留上一有效存档/会话重试 | 有限 JSON、拓扑一致、无旧句柄，不能静默重开而声称恢复成功 |
| 返回已经过的区域 | 梯、坞、W、气路、工具权限与存档一致 | 实体返回路真实存在，休眠折口不造成孤岛 |

以上均为待开发/待验证的行为合同，没有游戏自动化或真实试玩记录。后续每关只验证获授权阶段的相关条目，不以此矩阵作为一次性实现全章系统的授权。
