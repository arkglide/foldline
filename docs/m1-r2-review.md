# M1-R2：英语对白、双语字幕与最低角色演出

2026-10-18。范围仅C01-L01，基于已合并的R1与Windows启动修复，保留原生穿门、机关、实体楼梯及空间布局。没有制作S01、L02、自由放门、正式模型或全章剧情系统。

## 运行和设置

```sh
npm ci
npm run dev
```

本机浏览器打开 `http://127.0.0.1:4173`，启动后点击画面。WASD/鼠标移动观察，E交互（手轮按住、松手保持），R重试、Esc暂停；**V英语语音、B字幕、L中文/English字幕**。原游戏UI保留中文，新增设置及角色名随字幕语言本地化。默认中文，字幕选择不改变英语音轨。

V/B/语言通过原生 `ctx.storage` 单独保存，保持原projectId `foldline-c01-l01-m1`，不受关卡快照回溯。同源且存储可用时跨R、播放器重进和刷新保留。换协议/主机/端口、清除站点数据或禁用存储不保证保留；错误会显示“设置未保存”，不阻碍操作。读取期间已改的字段不会被迟到读取覆盖，写入串行合并，销毁后不新写或更新旧HUD。

## 对白和演出的具体变化

[完整15句英文/中文对照](voice-production.md)以[data v2](../game/data/l01-dialogue.json)为唯一源。原11句ID、角色、资源ID/文件和事件保留；`voiceText`是英语配音原文，`subtitles.en`与它一致，中文独立润色。英语姓名保留Zhanque/Hengwu，不另改人物身份。

栈雀猜门卡住、凭护栏联想到装货区，衡务依据记录作短纠正。栈雀对陌生空间有兴趣，会认错、惊讶，喜欢不靠电的退路，结尾想到后来需要楼梯的人；不是反复夸奖玩家。衡务按记录说明工作状态，克制而非反派化。4组 `after` 只在前句真正开始后才允许回应；未播猜测取消或过期，不补失去前因的回答。没有闲聊循环、听完才开的门或对白通关旗标。

新增可错过的 `upper.lookback`：首次原生穿越后，身体位于上层西侧观察带、目视A1柜冠约0.8秒，且原生射线先命中 `A1CabinetCrown`。截图证明认出来处折口柜，**不表示O1完整地坪或整个庭院无遮挡**。不进入胜利条件。

栈雀沿用12mesh/5材质、肩侧挂载、近门及贴栏收折，只对颔动、倾转和工具翼添加curious/dry/surprised/warm/matterOfFact的小幅节奏差别。不新增物理体、寻路或玩家位姿控制。缺英语WAV时是当前可见字幕驱动的临时演出，不是音素口型或振幅同步；既无可见字幕又无实际发声时不假装说话。首看出口后清零观察计时，修正长期滞留观察姿态的问题。

[九章角色发展建议](design/character-development.md)只补共同经历、有限判断、与衡务/许澈的关系及三结局代价，未实现后期事件。共管仍有降速与持续值守的成本，不新增完美默认结局。

## 实际声音与Windows制作

**已生成并接入的英语配音：0/15，全部待Windows制作。** Linux环境无System.Speech/PowerShell，未枚举实际声线、未合成或试听。4个已有机械WAV仍是真音效，不算配音。

[tts.ps1](../scripts/tts.ps1)列出实际离线声音，en-US优先、允许已安装en-*，优先不同音色，只有一条声线明确警告。可分别选声音或按ID重录，普通文本Speak以标点停顿，不依赖SSML。玩家浏览器只播放预生成文件，无需TTS安装。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/tts.ps1 -ListVoices
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/tts.ps1
node scripts/voice-assets.mjs --process
node scripts/voice-assets.mjs --check --strict
npm run dev
```

原始与成品metadata均升英语v2，绑定英语原文、角色、实际英语culture/声音、速率、音量和双SHA。旧中文清单/裸WAV被明确拒绝，已有旧录音需移出有效路径备份再生成英语。中文润色不使英语录音失效；英语改写必须重录。迁移、逐句重录、全部15个目标文件见[制作说明](voice-production.md)。

## 人工验收与停止点

需要确认：英文读音与口吻、中文语气、角色声音差异、台词会不会抢占观察、切换提示占屏、肩侧表演是否自然及上层回望是否可辨。实际WAV制作后，还需检验字幕跟随真实音频结束、音量、暂停恢复和快速通过时的节奏。

本轮仍是灰盒角色演出与技术验证，未通过正式美术/动画、声音演技或整关体验验收。提交推送任务分支后停止，等待用户试听和游玩，不合并main或进入下一关。
