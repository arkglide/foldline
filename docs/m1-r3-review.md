# M1-R3：L01 正式视觉样板候选

2026-10-18。基线为已合并main的R2（游戏提交`b5a110c178e1227962c1cc1d59422c6ec6608403`，main合并点`020598c`）。用户在本轮明确确认R2英文配音、双语字幕、栈雀和基础体验已通过人工试玩，批准推进L01正式美术。本交付只是一关的视觉样板候选；**视觉质量、音画协调、Windows性能和综合体验仍待用户审查**。未制作S01、L02、L03或整章场景。

## 实际运行

```sh
npm ci
npm run dev
```

本机浏览器打开`http://127.0.0.1:4173`，启动播放器、点击画面。WASD/鼠标移动观察，E交互（手轮按住、松手保持），空格跳跃、R重试、Esc暂停；V英语语音、B字幕、L中英字幕。原projectId及同源持久偏好保留，测试入口仍直接携带栈雀。

准备流程使用固定ArkGlide `da8ea1cf098ad99ccc89451d34bf4e272cdc15aa`，只同步运行时并经官方`createStaticGame`导出。美术源和小贴图随仓库提交；确定性构造自包含glTF，无需Windows安装建模工具、ImageMagick或额外运行依赖。不执行完整编辑器构建、不生成ZIP，运行时不请求在线素材。

## 空间、栈雀与画面边界

所有74个原生碰撞体、玩家胶囊及坐标/比例/朝向/运动描述逐项与R2相同；固定门、相机、穿越速度、手轮/百叶/闩、检查点与结束条件不改。纯静态装饰合批，运动和射线目标的稳定ID保留。新增泵顶管件局部达到约2.23m，但没有增加可站立碰撞；具体布局/可读性合同见[视觉设计](design/l01-r3-visuals.md)。

栈雀仍肩侧挂载，12mesh/5材质，新增1张共享金属texture；主壳18.9cm宽，细节合并进原活动部件。近门/贴栏退回肩侧、原生相机映射、暂停冻结、delivery动作和销毁合同保留。角色关系、15句对白、事件触发及英语制作策略未重写。

两盏原生点光加环境光；静态布景主要采用顶点烘色近似工作灯和接触暗部，小面积钢件用真实PBR/金属色图/法线。烘色不是GI或动态阴影。glTF用正确的手性/法线约定导出，没有移动玩家补偿资源坐标错误。

固定版无公开tone mapping/bloom/雾接口，未扩建引擎。只对canvas施加`saturate(0.94) contrast(1.025)`，字幕/HUD独立；没有模糊、景深、暗角、色差、颗粒或相机抖动。脚本销毁恢复样式，原生播放器停止还会移除整个运行iframe。

入口帧率约下降71%，近门约下降53%。这不是可忽略的变化，当前云端软件渲染不适合据此宣称流畅。mesh和引用材质已减少，但新增材质采样与几何仍有明显成本；这些数据不能外推Windows GPU必然相同，也不能反向保证其可接受。目标设备性能是待审项，不能仅凭较少mesh/材质宣称优化达标。

比较命令为`node scripts/benchmark-l01.mjs <已准备的静态目录> <r2或r3> <结果JSON>`。R2在`/tmp`从上述提交的`git archive`临时还原，复用只读固定引擎缓存后用原官方脚本准备；没有创建Git worktree。两个版本依次运行，每个版本每个位置两份2秒预热/6秒采样。相同1280×800、DPR1、FOV75、同一原生折口深度2/scale1/maxViews6；真实键鼠定位，不写玩家/相机坐标。实际姿态、渲染门数、资源、浏览器与CPU保存在JSON，位置并非逐像素相同；A1的R2两份样本均渲染4个门视图，R3为4/3个，所以这是近似位置的整场景比较，不能隔离某一材质成本。短时云端样本不是隔离GPU基准。

曾测过全场实时PBR，软件渲染代价很高；最终采用512px贴图、共享材质、静态装饰合批、静态烘色与有限PBR，未为掩盖成本调低折口渲染质量。额外研究检查了canvas滤镜和纯Standard替代，后者没有改善；[单次采样实验](evidence/m1-r3/sampler-investigation.json)中双线约4.79/三线约4.20 FPS，仅5秒入口研究样本，未作为正式性能结果或改用双线纹理的依据。游戏保持三线采样，未扩展到引擎重构。**当前仍有明显软件渲染退化，不能宣称性能无下降或Windows目标性能已验收。**

## 人工审查与停止点

请在本地目标设备重点确认：

- 入口第一眼是否仍自然看见高出口；偏暗区域和门冠的层次是否合适。
- 侧手轮、检视槽、A1/B1边缘及上侧闩是否容易辨认，装饰会不会被误认为新交互。
- 穿门后能否认出同一庭院，柜冠侧标是否有效，返梯的机械关系是否可信。
- 栈雀的新材质、体积、灯光和小动作是否协调；宽屏、快速转向、贴墙与门边是否舒适。
- 本地已生成英语配音与字幕在新环境中是否自然；不同音量、静音通关是否依然合适。
- Windows浏览器/GPU、分辨率、入口/近门帧率和加载情况；视觉收益是否值得实际性能成本。

本候选没有获得R3人工审查或综合验收。提交推送任务分支后停止，等待用户实际体验和反馈；不自动合并main、制作L02或扩展整章正式美术。
